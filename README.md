### Installation Instructions
1. Install [node.js](https://nodejs.org/en/download)
2. Clone the repo:
```bash
git clone https://github.com/martipops/latex2svg
```
3. Install dependencies and run the server:
```bash
cd latex2svg
npm i
npm run dev
```
4. Access the page at http://localhost:5173
